MacMusic User’s Guide

Appendixes A to D

Appendix A

Messages

This appendix lists every message MacMusic can show, in the order you’re likely to meet them, with what each one means and what to do. Messages that are questions have buttons; the one with the bold outline is chosen if you press Return.

Some messages end with a number in brackets, such as “(error −34).” It’s the Macintosh’s own code for what went wrong. The commonest are:

NumberMeans
−34the disk is full
−35the disk isn’t there
−39a file ended sooner than it should
−43a file couldn’t be found
−44, −46the disk is locked
−48the name is already in use
−49the file is already open
−108there isn’t enough memory
−120a folder couldn’t be found

Starting Up and Choosing a Library

“MacMusic keeps its songs in a folder called ‘MacMusic Library.’ Find an existing one, or create a new one.”

MacMusic has no library yet. Click Find Existing to open one you have, Create New to make one, or Not Now to carry on without one; you can choose a library later with Choose Library in the File menu.

“The MacMusic Library folder could not be found. Its disk may not be inserted, or it may have moved. Find it, or create a new one.”

The library you used last time isn’t where it was. Insert its floppy disk, or switch on its hard disk, and click Find Existing; or click Create New, or Not Now.

“That MacMusic Library can’t be found. Its disk may not be inserted, or it may have moved.”

You chose a library from the File menu that isn’t there. Insert its disk or switch it on, and choose it again; if it has moved, use Choose Library.

“Use an existing MacMusic Library, or create a new one? To use an existing library, open its ‘MacMusic Library Info’ file or one of its songs.”

You chose Choose Library. Click Use Existing Library or Create New Library, or Cancel.

“That file isn’t inside a MacMusic Library. Open the ‘MacMusic Library Info’ file, or a song, in the library’s folder.”

The file you opened isn’t part of a library. Open the library’s folder and choose its MacMusic Library Info file.

“This folder is already a MacMusic Library. Use it, instead of creating a new library inside it?”

You chose to create a library inside an existing one. Click Use It to use the existing library, or Cancel to choose another place.

“A file with that name is already there. Choose another name or place.”

There’s already a file with the name you gave the new library. Type another name, or choose another folder.

“The library location could not be remembered.”

MacMusic couldn’t save its preferences, perhaps because the startup disk is locked or full. The library is open; MacMusic will ask for it again next time.

“There is not enough memory to read the MacMusic Library.”

Quit other applications and try again, or give MacMusic more memory (see “MacMusic and Your Other Applications” in Chapter 2).

“1 file in the MacMusic Library was not recognised and was skipped.” (or “n files … were”)

The library’s folder holds files that aren’t MacMusic songs, or a song with the same number as another (copied in from another library, say). Take out any files you put there with the Finder. Library Info shows how many files couldn’t be read.

“n songs weren’t loaded: the MacMusic Library holds at most 500 songs. Export songs to make room.”

The library’s folder holds more than 500 songs, so some were left out. Export songs you don’t want, then choose Rescan Library.

“n playlists weren’t loaded: MacMusic can have up to 10 playlists.”

The Playlists folder holds more than ten playlists. Delete one you don’t want, then choose Rescan Library.

Importing Songs

“Importing from another disk will take some time. Do you still want to import?”

The file is on a floppy disk or another hard disk, so it has to be copied. Click Import, or Cancel.

“The file will be moved into the MacMusic Library. Choose Just Copy to leave the original where it is (copying takes longer).”

Click OK to move the file into your library (from another disk, MacMusic copies it and then removes the original), or Just Copy to keep the original where it is.

“This file is locked, so it can’t be moved. Copy it into the MacMusic Library instead?” and “This file is in use or its disk is locked, so it can’t be moved. Copy it into the MacMusic Library instead?”

Click Copy to import a copy, leaving the original as it is, or Cancel.

“This WAV file’s audio is already in the MacMusic Library as ‘title’. Import it again?”

The song is already in your library, perhaps under another name. Click Cancel, or Import Anyway to have it twice.

“This is not a WAV file.”

MacMusic can import only WAV sound files. Click OK.

“Only mono, 22050 Hz, 8-bit PCM WAV files can be imported. This file is stereo, 44100 Hz, 16-bit.”

The file is a WAV file of another kind; the message says what it is. It has to be made into the kind MacMusic plays: see Appendix B, and MacMusic Utilities.

“This WAV file is not plain PCM audio (it may be compressed or floating-point). Only uncompressed PCM WAV files can be imported.” and “This WAV file uses the extensible format, which can’t be imported. Save it as plain PCM.”

The file holds its sound in a form MacMusic can’t play. It has to be prepared again; see MacMusic Utilities.

Messages saying the WAV file is damaged or incomplete, has no format information or audio data, or that its format information is inconsistent

The file is damaged, or wasn’t finished when it was made. Make a new copy from the original.

“The file could not be opened.”, “The file could not be found.” and “The WAV file could not be read.”

The file was removed, or its disk ejected, or the disk is damaged. Check the disk, and try again.

“This file is already inside the MacMusic Library folder.”

It’s already one of your songs. Choose a file from outside the library.

“The MacMusic Library is full (500 songs). Export a song to make room.”

Export a song you no longer want, or start another library.

“There is not enough memory to import a song.”

Quit other applications, or give MacMusic more memory.

“There is not enough space on the MacMusic Library’s disk for this song.”

Make room on the disk by throwing away files you don’t need, or by exporting songs; then import the song again.

“The song could not be imported.”

Something went wrong while the song was copied or moved; the number in brackets says what. The song isn’t in your library. Check the disks, and try again.

“The song was imported, but the original file couldn’t be removed from its disk, so it was left in place.”

The song is in your library. Its original is still on the other disk, probably because the disk is locked; throw it away yourself if you like.

“Please enter a title.” and “Track must be a whole number from 0 to 9999.”

In the song’s details, type a title (every song needs one), and a track number of 9,999 or less, or leave the track empty.

“The song details window could not be opened.”

There isn’t enough memory. Quit other applications, and try again.

Changing and Exporting Songs

“Choose a folder outside the MacMusic Library.”

An exported song can’t be saved inside the library. Choose another folder.

“That folder could not be found.” and “There is not enough space on that disk.”

Choose another folder or disk, or make room, and export again.

“The song could not be exported.”

The song is still in your library. Check the disk you chose, and try again.

“The song was exported, but its file couldn’t be removed from the MacMusic Library.”

The exported file was saved, but the song is still in your library. Check that the library’s disk isn’t locked, and choose Rescan Library.

“The song was exported, but it couldn’t be given the name you chose, so it kept its MacMusic Library name.”

The file was saved under its number instead. Rename it in the Finder.

“The song’s file could not be read.”

The song’s file is damaged, or its disk has gone. Check the disk; you may need to import the song again from the original.

“The song’s details couldn’t be saved.”

The details weren’t changed, perhaps because the disk is locked or full.

“The song’s details were saved, but its title couldn’t be updated in every playlist.”

The song is changed. Playlists list songs by number, so they still work; only the title written in a playlist file for people to read is out of date.

Playlists

“MacMusic can have up to 10 playlists.”

You already have ten. Delete one you no longer want first.

“Please enter a name for the playlist.”, “Playlist names can be at most 31 characters long.” and “Playlist names can’t contain a colon (:).”

Type a name of 1 to 31 characters, without a colon.

“There is already a playlist with that name.” and “There is already a file with that name in the Playlists folder.”

Each playlist needs a name of its own. Type another.

“‘title’ is already in the playlist ‘name’. Add it again?”

Click Add Again to have the song on the playlist twice, or Cancel.

“Delete the playlist ‘name’? The songs in it stay in the library.”

Click Delete to delete the playlist, or Cancel to keep it.

“The playlist could not be created.”, “… renamed.”, “… deleted.”, “The song could not be added to the playlist.” and “The song could not be removed from the playlist.”

The playlist’s file couldn’t be changed, perhaps because the disk is locked or full. Nothing was changed.

Playing

“Sound playback isn’t available; songs will play silently.”

MacMusic can’t use the Macintosh’s sound. Songs still “play,” with their times shown, but you won’t hear them. MacMusic is made for the Macintosh Plus.

“A song’s file couldn’t be read, so it was skipped.”

A song’s file is damaged, or its disk has gone. MacMusic went on to the next song. Choose Rescan Library; if the song still won’t play, export it and import it again from the original.

“The song’s rating couldn’t be saved.”

The rating wasn’t changed, perhaps because the library’s disk is locked or full.

Appendix B

About Sound Files

The Files MacMusic Plays

MacMusic plays WAV sound files of one kind:

  • mono: one channel of sound;
  • 22,050 samples a second;
  • 8 bits to each sample, uncompressed (“PCM”).

That’s the Macintosh Plus’s own sound. Its sound hardware plays 8-bit samples, about 22,000 a second, through one channel, to the built-in speaker or the sound output port. A file made for it plays just as it was made, with nothing lost along the way, and the Macintosh has time left over for everything else.

Because the Macintosh has one sound channel, MacMusic’s sound is mono, through the speaker and the sound output port alike. A stereo recording is mixed into one channel when its file is made.

The Macintosh Plus actually plays 22,254 samples a second, so songs play about 0.9% faster than they were recorded: a four-minute song ends two seconds early. Few ears can tell, and the times MacMusic shows are right.

How Much Room Music Takes

At 22,050 bytes a second, music takes about 1.3 MB of disk space for each minute. So:

OnThere’s room for about
An 800K floppy disk30 seconds, beside MacMusic itself
A 20 MB hard disk, such as the Apple Hard Disk 20SC15 minutes, or four or five songs
An 80 MB hard diskan hour
A 2 GB hard disk, the largest System 6 can use25 hours

A full library of 500 songs, at four minutes a song, would need about 2.6 GB, more than one disk can hold; you can keep a library on each of several disks, and switch between them with the File menu.

Settings, About, and Library Info in the File menu both show how much room is left on the library’s disk.

Where Songs Come From

MacMusic plays the files; it doesn’t make them. Your music has to be prepared as MacMusic’s kind of WAV file, and brought to the Macintosh, before you can import it. MacMusic Utilities, a separate manual, explains how: see “Converting Songs.”

If a file isn’t the right kind, MacMusic says so when you import it, and says what the file is. The messages are listed in Appendix A, under “Importing Songs.”

Appendix D

Troubleshooting

If something isn’t working as you expect, look for it here. For a message MacMusic shows, see Appendix A.

No sound

Go to Now Playing and turn the click wheel clockwise: the volume may be turned down.

Check the sound output port on the back of the Macintosh. While anything is plugged into it, the built-in speaker is silent; if headphones or a speaker are connected, check them, and their own volume.

If MacMusic said “Sound playback isn’t available,” it can’t use this Macintosh’s sound; MacMusic is made for the Macintosh Plus.

MacMusic can’t find your library

Insert the library’s floppy disk, or make sure its hard disk is connected and switched on. Switch an external hard disk on before you switch on the Macintosh, so the Macintosh finds it as it starts up.

Then click Find Existing and open the library’s MacMusic Library Info file, or choose the library from the File menu.

A file won’t import

MacMusic says why; see Appendix A, “Importing Songs.” Most often the file isn’t MacMusic’s kind of WAV file. MacMusic Utilities explains how to prepare one.

The music pauses while another application works hard

MacMusic plays in the background, but if another application keeps the Macintosh completely busy for more than about six seconds (copying many files, say, or initialising a disk), the sound can run out. You may hear a moment repeat, then a pause; the music carries on by itself when the Macintosh is free.

Not enough memory under MultiFinder

MacMusic asks for 640K, and needs at least 512K. Quit applications you aren’t using, or give MacMusic less memory with Get Info (see Chapter 2).

Starting up takes a while

MacMusic reads your whole library each time it starts, and when you choose Rescan Library: a minute and a half to two minutes for 500 songs. You’ll see the wristwatch while it reads.

Songs play a little fast

By about 0.9%, because the Macintosh Plus plays its sound a little faster than the files were made for. The times shown are right. See Appendix B.

The softest volume isn’t silent

It’s the Macintosh Plus’s lowest sound level. To silence the music, pause it.

“A song’s file couldn’t be read”

The song’s file is damaged, or its disk has gone. Choose Rescan Library. If the song still won’t play, export it and import it again from the original file.

A song is missing from the lists

An audiobook is listed only under Audiobooks; check the song’s Audiobook box with Edit Song. If the song was copied into the library folder with the Finder, MacMusic may have skipped it: import songs with Import Song instead.
