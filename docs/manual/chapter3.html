Elements of MacMusic

MacMusic works with three things: a library, the songs in it, and playlists. This section describes each, and its limits.

The MacMusic Library

A MacMusic Library is a folder, on any disk, that holds your songs and playlists. MacMusic uses one library at a time; you can have as many as you like, and switch between them with the File menu. Inside the folder are:

  • MacMusic Library Info, a small file that marks the folder as a library. To open a library, you open this file.
  • Playlists, a folder holding a text file for each playlist.
  • a song file for each song, named by its number.

Each song is given a number of its own when it’s imported. A number is never used twice in the same library, even after its song has been exported.

MacMusic reads the whole library each time it starts, and when you choose Rescan Library. For a library of 500 songs, that takes between a minute and a half and two minutes.

Only MacMusic should change a library’s files. A song file copied in from another library may have the same number as one already there; two songs with the same number can’t both be used, and MacMusic tells you which one it has left out.

MacMusic keeps its preferences (the library in use, the libraries you’ve used before, the volume and the settings) in a file called MacMusic Prefs, in the System Folder.

Songs

A song file is the WAV file you imported, unchanged, with MacMusic’s details for it added at the end. That’s why importing can simply move a file into the library, and why exporting gives back exactly the file you imported. Each song has:

  • a title, which every song must have;
  • an artist, an album, a genre and a composer, any of which can be left empty;
  • a track number, from 1 to 9,999, or none;
  • the Audiobook box, checked or not;
  • a rating: none, or one to five stars.

The title and the other details can be up to 63 characters each. An audiobook is a song with its Audiobook box checked: it’s listed only under Audiobooks, and never shuffled.

Playlists

A playlist is a text file in the library’s Playlists folder, named after the playlist. Each line lists one song, by its number and, for anyone reading the file, its title; MacMusic reads only the number. A song can be on a playlist more than once. Exporting a song takes it off every playlist.

  • A library can have as many as 10 playlists.
  • A playlist’s name can be up to 31 characters, and can’t contain a colon (:).
  • MacMusic reads as many as 1,000 songs from one playlist.

MacMusic’s Screens

MacMusic’s screen shows one list at a time. A > at the right of an item means it leads to another list; a scroll bar at the right means the list is longer than the screen.

The Main Menu

  • Music leads to everything in your library.
  • Extras holds the Clock.
  • Settings holds Shuffle, Repeat and the others; see “Settings in Detail.”
  • Shuffle Songs plays every song but the audiobooks, in a random order.
  • Backlight turns the screen light on dark, and back.
  • Now Playing appears at the end of the menu while a song is playing or paused.

Extras

Extras holds the Clock, which shows the time and date from the Macintosh’s own clock, kept up to the minute.

Now Playing

Now Playing shows the song that’s playing: where it is in the list, its title, artist and album, a bar showing how much has played, and the time played and the time left. At the top left, an icon shows whether it’s playing, paused, or moving fast; at the top right, the Shuffle and Repeat icons appear when they’re on (the Repeat icon is the same for One and All).

On Now Playing, turning the click wheel changes the volume, and the volume bar shows for two seconds. Clicking the centre button steps through the scrubber, then the rating, then back to the progress bar; the scrubber and the rating go away by themselves after five seconds.

Apple Menu

The Apple menu holds About MacMusic and your desk accessories.

About MacMusic…

Shows MacMusic’s version and copyright. Click OK to put it away.

Desk accessories

The music plays on while you use any desk accessory. Two are particularly useful with MacMusic:

  • Alarm Clock sets the Macintosh’s clock, which MacMusic’s Clock shows.
  • Control Panel sets the speaker volume, which is MacMusic’s volume too. When MacMusic starts, it sets the volume to the level you last chose in MacMusic.

File Menu

The File menu’s commands look after your library: what goes into it, what comes out, and which library you’re using.

Import Song…

Asks for a WAV file and imports it into the library; see “Adding Songs” in Chapter 2. Dimmed when no library is open.

Export Song…

Gives the highlighted song back as its original WAV file, and removes it from the library and from every playlist. Dimmed unless a song is highlighted.

Choose Library…

Asks whether to use an existing library or create a new one, and switches to it.

Rescan Library

Reads the library’s folder again. Dimmed when no library is open.

Library Info…

Shows how many songs the library holds (out of 500) and how many playlists, how much room the songs take, how much is free on its disk, and how many files couldn’t be read.

Libraries used before

Up to five, with the one in use checked. Choose one to switch to it. A library whose disk isn’t there is dimmed.

Quit ⌘Q

Stops the music and quits MacMusic. MacMusic remembers the library, the volume and the settings for next time.

Edit Menu

The Edit menu is where you change a song’s details.

Undo, Cut, Copy, Paste, Clear

MacMusic has nothing to cut or paste, so these are dimmed.

Edit Song…

Shows the details of the highlighted song, or of the song on Now Playing, for you to change. Save keeps you on the same screen. Dimmed unless a song is highlighted or playing.

Playlists Menu

Everything to do with playlists is in the Playlists menu. Its commands act on the playlist or song highlighted on MacMusic’s screen.

New Playlist…

Asks for a name (“Untitled Playlist” is suggested) and makes an empty playlist. If you already have ten, MacMusic says so instead.

Rename “name”…

Renames the playlist highlighted in the Playlists list, or the one you’re in. Otherwise it reads Rename Playlist, and is dimmed.

Delete “name”…

Deletes that playlist, after asking you; Cancel is the default. Its songs stay in the library. Otherwise it reads Delete Playlist, and is dimmed.

Remove from Playlist

Takes the highlighted song off the playlist you’re in. The song stays in the library. Dimmed elsewhere.

Add to “name”

One for each playlist. Adds the highlighted song at the end of that playlist, asking first if it’s already there. Dimmed unless a song is highlighted.

Settings in Detail

Choose a setting and click the centre button to show its next value. MacMusic remembers the settings.

Songs (how many, out of 500), Available (the free space on the library’s disk) and Version.

The legal statement, in full. Turn the click wheel to read it.

Reset All Settings

Cancel or Reset. Reset puts Shuffle and Repeat back to Off; the volume is left as it is.
